# YourNote frontend

Run from the project root:

```bash
./scripts/dev_backend.sh
# In a second terminal:
./scripts/dev_frontend.sh
```

Open http://127.0.0.1:5173 to see the notebook home. Create a notebook or open
an existing one to use Sources, Chat, and Studio (Summary, Quiz, Flashcards, Mind Map, Notes).
Each notebook saves its own source membership, selected pages, conversation,
and generated results. Add existing PDFs with **Thêm từ thư viện**, or upload
a new PDF. Page filtering is available when exactly one PDF is selected.
Run one FastAPI worker for embedded Qdrant.

Each source has a separate **Đã đọc** checkbox. This tracks reading progress
independently of the source selection used for Chat/Studio and the page filter.
Use **Tất cả / Chưa đọc / Đã đọc** to filter the list. Opening a PDF in deep
reading also marks it as read; the status can be unchecked manually. Read flags
are per notebook and are cleared when the source is detached from that notebook.

Studio's **Ghi chú** section supports manual notes with titles and plain-text
content, creating/editing/deleting notes, and an expanded editor. Notes need no
selected source and make no Gemini requests. Notes and read flags autosave in
the notebook workspace, survive reopening/reloading, and are isolated between
notebooks. Each notebook supports up to 100 notes, with 160-character titles
and 100,000-character bodies. Old notebooks default to empty notes/read flags.

The home supports title search, recent/conversation filters, sorting, list/grid
views, renaming, and deletion. Deleting a notebook removes its saved workspace;
its PDFs remain in the shared document library. Existing indexed PDFs are
migrated once into **Tài liệu nghiên cứu** on first use.

The header's **Cài đặt** button offers **Đặt lại sổ tay**. From the home, choose
one notebook; inside a workspace, the current notebook is selected. Enter
**ĐẶT LẠI** and confirm to clear that notebook's sources, aliases, selections,
conversation, manual notes, read flags, Studio results, and legacy highlights. Its identity, title, icon, and
home entry remain, as do all other notebooks and the shared PDF/index library.
Reset waits for pending workspace saves and is disabled during active work.
Canceling settings leaves saved content intact; normal use keeps autosaving.

Notebooks are saved automatically in `storage/notebooks.sqlite` alongside the
existing Qdrant directory. Back up both the database and `data/`/`storage/qdrant/`
to retain notebooks and their documents. This is a local workspace without
multi-user authentication. View and theme preferences use browser local storage.

Use the sun/moon button in the home header to choose light or dark mode. The
selected palette also applies to the notebook workspace, viewers, and dialogs,
and is restored before the next page renders. On desktop, the source and Studio
panels can be collapsed to make more room for the conversation. On mobile, use
the Sources/Chat/Studio tabs to move between panels without losing their state.
Drag the separators beside Sources and Studio to resize either panel. Widths
are remembered in browser local storage and adapt to the available space while
reserving room for Chat. Double-click a separator to reset that side; focused
separators also support arrow keys, Shift+arrow, Home/End, and Enter to reset.
Suggested questions fill and focus the composer; generation starts only when
you send a question or explicitly create content in Studio.

Studio also offers **Sơ đồ tư duy**. Select sources (and optionally a page or
topic), create a map, then choose **Mở sơ đồ**. The viewer supports pan/zoom,
fit-to-screen, collapsible branches, node explanations, and node-specific
citations that open the original PDF in deep reading. **Hỏi về ý này** selects
the node's available source PDFs and fills the chat composer; it does not send
the question automatically. Maps autosave with the notebook, survive reloads,
and are cleared by that notebook's reset. Export the visible branches to SVG,
or the complete tree with citations to Markdown.

Mind maps are generated by `/api/mindmap`, using the existing selected-source
and page filters. An optional topic uses scoped retrieval. Without a topic,
all matching chunks are processed in batches and their sourced outlines are
merged recursively; long documents can require several model calls. Citation
IDs remain global across batches and are checked before returning the map.
Trees are limited to 4 levels, 65 nodes, and 8 children per node; unsupported
leaf citations or malformed output fail instead of saving an uncited map.
Mind-map batches default to 24 chunks (`RAG_MINDMAP_BATCH_SIZE`, 1–64),
independently of summary batches. Gemini requests retry temporary server or
transport failures up to 3 total attempts, with short backoff and a 60-second
timeout per attempt. Quota/authentication failures are reported without retries.
Provider overload, quota and timeout responses have distinct safe messages.
CORS wraps the full API so even unexpected errors reach the browser as HTTP
responses instead of being mistaken for connection failures.

Each source's vertical **⋮** menu offers **Đọc chuyên sâu** and **Tải PDF gốc**.
Use **Đổi tên nguồn** in that menu to save a display name for this notebook.
The name appears in the source list, PDF picker, and citations; the original
filename, document identity, downloads, and annotations remain intact. Different
notebooks can assign different names to the same PDF.
Deep reading replaces the sidebars with an original PDF reader next to the same
conversation. The divider resizes the PDF/chat split; mobile uses PDF/Chat tabs.
Opening a source in deep reading also checks it in the notebook's source
selection. Returning to the notebook retains that selection, along with any
sources already checked, and saves it with the workspace.
The reader supports paging, zoom, original downloads, and native text selection.
Selecting PDF text exposes only **Sao chép**. Copy it with that button or the
browser's normal copy command, then paste into chat if needed. Highlight tools,
saved-highlight overlays, and the selected-passage question shortcut are no
longer displayed. Existing annotation records and historical chat context are
retained for compatibility; the reader makes no annotation requests.
Scanned pages need OCR before text selection is possible; automatic OCR is not
included.

Reading chat defaults to the open document, with an explicit whole-notebook
option. Source scope is saved with each chat turn. Clicking a chat citation
opens its original PDF page and shows the cited excerpt. PDF.js and its worker
are bundled locally without a CDN.

The API base URL defaults to `http://127.0.0.1:8000`. To override it, copy
`.env.example` to `.env.local` and change `VITE_API_BASE_URL`, then restart Vite.
Vite environment values are public: never put Gemini keys or other secrets here.

For this workspace's local Node installation, run from the project root:

```bash
export PATH="$PWD/.tools/node/bin:$PATH"
cd frontend
npm ci
npm run build
npm run preview -- --host 127.0.0.1
```

`package-lock.json` records the installed dependency versions. Generated results
and chat history survive reloading or reopening a notebook; transient quiz
answers and card positions reset when the workspace is reopened. Check **Đã lưu**
before closing the page; a failed save offers a retry. Use **Tải Markdown** to
download a result through the backend export endpoint.
